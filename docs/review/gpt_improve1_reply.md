一、为什么你目前的 Agent 会表现得不够智能？
我认为问题至少存在于三个层次。
1. Agent 把天线设计当成了黑箱优化
假设某个漏波天线有以下参数：
\[ \mathbf{x}=[p,h,w,g,N,\ldots] \]
其中包含周期长度、单元高度、宽度、间隙和周期数。
你希望同时实现：
工作频段内良好的阻抗匹配
足够宽的工作带宽
满足要求的增益
正确的主波束指向
尽可能低的副瓣电平
普通 Agent 往往采用：
修改参数
HFSS 仿真
比较结果
效果不好就继续修改，反复循环
但问题是，它可能不知道：
哪个参数主要影响相位常数，哪个参数主要影响漏波常数。
为什么改变周期长度会引起主波束偏移。
为什么降低反射系数，有时反而会恶化辐射性能。
什么时候应该停止微调参数，转而修改辐射单元的结构。
更重要的是，它往往缺少明确的判断机制：当前设计究竟是参数没有调整好，还是结构本身无法实现全部指标？
优秀天线工程师与普通优化程序的重要区别，就在于能够识别这种问题。

3. 遗传算法只能搜索你允许它搜索的结构
这是我认为最值得你关注的问题。
如果你把漏波天线描述为固定结构的 12 个几何参数，那么遗传算法所做的全部工作，本质上就是：
\[ \min_{\mathbf x\in\Omega}F(\mathbf x) \]
但是，如果最佳设计需要改变单元形状、引入新的槽、采用不同的对称性或调整单元排布方式，这些方案根本不在原来的搜索空间内。
遗传算法可以寻找一种结构的最佳参数，却不能自动发现你没有定义的新结构。
这意味着，哪怕使用非常先进的优化算法，也可能始终无法突破原始天线拓扑的限制。
所以你的系统需要区分两个任务：
参数级优化：结构不变，修改尺寸、角度、间距等。
结构级优化：改变辐射单元形状、周期性、对称性、加载方式或整体构型。
第二个任务，才是你希望 Agent 获得的更高级设计能力。

三、四个最值得编写的算法模块
模块 1：带约束的多目标优化，解决“捡了芝麻丢西瓜”
这是我建议你第一个完成的模块。
首先，不要把所有天线指标都混进一个加权适应度函数，而是区分：
硬约束：必须满足，不允许通过牺牲它们换取其他收益。
例如，在指定频率集合 \(\mathcal F\) 内：
\[ \begin{aligned} &S_{11,\mathrm{dB}}(f)\leq-10\,\mathrm{dB}\\ &G_{\mathrm{realized}}(f)\geq 16\,\mathrm{dBi}\\ &|\theta_{\mathrm{main}}(f)-\theta_{\mathrm{target}}(f)|\leq2^\circ\\ &\mathrm{SLL}(f)\leq-15\,\mathrm{dB} \end{aligned} \]
以上数值只是示例，实际需要根据你的设计指标设置。
优化目标：在满足约束的基础上，尽可能提高。
比如最大化最差频点的实现增益、提高辐射效率、缩小结构体积，或者扩大满足全部性能要求的有效工作带宽。
这里有一个很重要的细节：
不要仅仅优化 \(-10\,\mathrm{dB}\) 阻抗带宽，而应该优化同时满足阻抗、增益和方向图要求的综合有效带宽。
否则 S11 很漂亮，天线却未必能在整个频带正常辐射。
对于遗传算法，我建议优先采用 NSGA-II + 可行性优先的约束支配规则：
可行方案优先于不可行方案。
两个可行方案采用 Pareto 支配关系比较。
两个不可行方案优先比较总约束违反程度。
保留多样化的非支配解，而不是只保留一个最高分个体。
这样就不会因为某次带宽改善而自动淘汰另一套拥有良好方向图的方案。
Pareto 前沿的概念示意
概念示意，假设这两个指标存在权衡。纵横坐标均越大越好，曲线上的方案不存在简单的绝对优劣。
这种方法不会替你决定哪个方案最好，而是尽量保留值得工程师考虑的方案。
模块 2：代理模型 + 贝叶斯优化，减少昂贵的 HFSS 仿真
第二个模块我认为可以显著提高实际效率。
遗传算法的一大问题是消耗的全波仿真次数较多。
例如种群 40，进化 30 代，理论上最多会产生约 1200 次候选方案评估。即使复用重复结果，仍然可能非常昂贵。
对此，我更倾向于：
\[ \text{HFSS}\longrightarrow\text{代理模型} \longrightarrow\text{优化候选点} \longrightarrow\text{HFSS 验证} \]
其工作方法如下：
使用拉丁超立方采样或 Sobol 序列生成一批初始几何参数。
通过 HFSS 计算响应，建立真实仿真数据库。
使用高斯过程回归（GPR）、RBF 或神经网络训练代理模型。
在代理模型上完成大规模候选搜索。
选择最值得验证的候选方案，交给 HFSS 精确计算。
将新结果加入数据库，更新代理模型，重复循环。
这里与普通机器学习预测有一个重要区别：
不是让神经网络代替 HFSS，而是让它帮助判断下一次 HFSS 最值得计算什么。
对于参数不太多、HFSS 单次仿真很昂贵的问题，我建议考虑贝叶斯优化。
如果是多个目标，可以考虑 BoTorch 提供的 qLogNEHVI 等多目标采集函数；如果搜索空间更大，也可以采用代理模型辅助的差分进化或 NSGA-II。
GitHub+1
这并非仅仅是理论方案。2026 年已有研究将混合变量、多目标贝叶斯优化应用于 HFSS 像素化天线设计，在相应测试任务中减少了达到设计目标所需的全波评估次数。
Arizona Board of Regents
不过，对于结构发生较大改变的情况，旧代理模型可能完全失效。因此需要给每个结构族分别建立模型，或者采用能够处理离散结构变量的混合优化方法。
模块 3：灵敏度矩阵，让 Agent 知道应该改哪里
我认为这个模块对于你的周期漏波天线尤其重要。
对于当前天线，设参数向量为：
\[ \mathbf{x}=[x_1,x_2,\ldots,x_n]^T \]
设计性能向量为：
\[ \mathbf{y}=[BW,G,SLL,\theta,\eta,\ldots]^T \]
建立局部灵敏度矩阵：
\[ \mathbf J= \frac{\partial \mathbf y}{\partial \mathbf x} \]
在 HFSS 中可以通过少量扰动仿真做中心差分估计：
\[ J_{ij}\approx \frac{y_i(\mathbf{x}+\Delta x_j\mathbf e_j) -y_i(\mathbf{x}-\Delta x_j\mathbf e_j)} {2\Delta x_j} \]

有了这个矩阵，Agent 就可以进行真正有针对性的修改。
例如：
当前方向图已经合格，但 S11 不合格。
传统 Agent 可能继续调整所有参数。
新的 Agent 会首先寻找：
\[ \Delta\mathbf{x} \]
使得阻抗匹配改善，同时尽量满足：
\[ |\Delta G|\leq\varepsilon_G,\qquad |\Delta\theta|\leq\varepsilon_\theta \]
这可以转化成一个带约束的局部优化问题：
\[ \begin{aligned} \min_{\Delta\mathbf x}\quad& \|\mathbf J_{\mathrm{target}}\Delta\mathbf x -\Delta\mathbf y_{\mathrm{desired}}\|_2^2\\ \text{s.t.}\quad& |\mathbf J_{\mathrm{protected}}\Delta\mathbf x| \leq\boldsymbol{\varepsilon}\\ &\|\Delta\mathbf x\|\leq r \end{aligned} \]
其中 \(r\) 是局部信赖域半径，防止一次修改过大，使线性近似失效。
这实际上让 Agent 获得一种很重要的能力：
知道哪些参数可以改善当前问题，同时尽量不破坏已经达标的指标。
当然，它依然是局部近似。如果连续几次发现预测与 HFSS 实际结果相差很大，就应该缩小信赖域或重新估计灵敏度，而不是继续盲目调整。

我建议你不直接让 LLM 自由编写任意 HFSS 建模代码，而是建立一个结构操作库。
比如对金属周期漏波天线，可以定义：

由代码执行结构修改、几何有效性检查和全波验证。

\[ \mathrm{Antenna}= \mathrm{Feed}+\mathrm{UnitCell}+ \mathrm{ArrayProfile}+\mathrm{Termination} \]

这比直接让 LLM 随机修改 CAD 模型更可控、更容易积累经验，也更适合 3D 打印制造约束。
四、结合你的研究方向，我会设计两套不同的物理引导策略
这部分是整个系统能否真正超越普通参数优化器的关键。
1. 金属周期结构漏波天线：先优化色散和漏波，再优化整天线
对采用空间谐波辐射的周期漏波天线，其主波束角可以近似表示为：
\[ \theta\approx\sin^{-1}\left(\frac{\beta_n}{k_0}\right) \]
其中：
\[ \beta_n=\beta_0+\frac{2n\pi}{p} \]
对于常见的 \(-1\) 次空间谐波：
\[ \beta_{-1}=\beta_0-\frac{2\pi}{p} \]
因此，周期长度及单元色散特性与主波束方向存在明确的物理联系。
Nature+1
你可以利用这类关系，让 Agent 优先分析：
相位常数 \(\beta\)：决定辐射方向以及随频率变化的扫描特性。
漏波常数 \(\alpha\)：影响沿线辐射能量分布、有效孔径长度和辐射效率。
输入阻抗及反射：影响端口匹配，且不能简单等同于辐射效果。
开阻带及模态耦合：对于需要穿越边射方向的周期漏波天线尤其重要。
我更建议你让系统采用分级仿真：
第 1 层
周期单元分析
提取色散关系、模态信息，并在适当模型下估计复传播常数
第 2 层
有限周期结构分析
验证馈电、反射、辐射泄漏和有限尺寸效应
第 3 层
完整天线仿真
检查全频带 S11、实现增益、方向图、副瓣和效率
这里需要注意：仅通过普通无损单元的本征模色散图，不一定能可靠地求出实际有限长度天线的漏波常数，必须选择适合辐射模态的提取方法，并用有限结构验证。
这套方法的优势是，你可以把一些本来需要完整 3D 天线仿真才能发现的问题，提前到单元级处理。
例如，2026 年的一项 3D 打印全金属 SSPP 漏波天线研究，就是利用 Glide 对称性改变色散，并通过非对称周期调制实现辐射及抑制开阻带效应。这恰好是结构级设计决策的例子，而不只是参数扫描。

2. 透镜天线：优化整个孔径电磁场，而不仅是几何参数
透镜天线要根据类型区分。
如果你做的是传统金属反射透镜，需要重视反射面的形状、馈源位置和口径照明；如果是透射型金属超表面透镜，则需要重点关注单元透射幅度、相位和色散。
以馈源位于轴上焦点、目标为正向准直波束的平面透射型超表面透镜为例，理想相位补偿通常可以写为：
\[ \phi(x,y)=k_0\left(\sqrt{x^2+y^2+f^2}-f\right) \pmod{2\pi} \]
其中相位符号取决于所采用的时谐场约定。

五、怎么判断应该继续调参，还是重新设计结构？
我建议你自己写一个结构升级判别器，这是系统里非常值得研究的功能。
它可以根据过去若干次仿真的结果，自动决定下一步采用哪类搜索策略。

所有指标合格，但某些性能仍有提升空间
多个指标持续冲突，调整一个就恶化另一个
连续多轮没有改善，预测与仿真偏差也很大
同一结构族长期无法满足硬约束
推荐下一步操作
检查 Pareto 前沿及灵敏度耦合
真正实现时，不能仅根据一句自然语言做决策，还应该使用数值规则，例如连续多轮 Pareto 超体积改善量过小、所有候选方案违反某个硬约束，或者局部灵敏度显示无法在允许扰动内修复关键指标。
特别是遇到“同一个结构族始终无法同时满足指标”的情况，就应该鼓励 Agent 尝试新的结构，而不是无限次调用 HFSS。
六、与你现有的 MCP 工作流怎么结合？
我建议保留 MCP，但要重新定义它的职责。
MCP 是操作通道，不应该承担优化算法本身。
HFSS 自动化层可以用 PyAEDT 实现。Ansys 已经提供了 PyAEDT-MCP 的完整 HFSS 工作流示例，包含 AEDT 连接、设计创建、仿真和脚本调用等能力。

实际系统中，我还会加入三个工程机制。
第一是自动回滚。 每次仿真前保存原始设计，不允许一个失败的结构修改覆盖已有的优秀方案。
第二是完整仿真记录。 不仅保存最终适应度，还要保留全频段 S 参数、方向图、增益、效率、几何参数、网格收敛状态和仿真配置。否则代理模型学到的可能是数值误差。
第三是制造鲁棒性优化。 你的结构采用金属 3D 打印，还应检查最小壁厚、最小间隙、封闭腔内残粉清理、支撑可行性，以及尺寸公差造成的性能变化。最终候选方案最好进行公差扰动验证，而不是只优化理想 CAD 模型。
七、如果我来做这个项目，会按什么顺序推进？
我不会一开始就开发一个很复杂的自主设计 Agent，而是分成三个阶段：
建议首先选择一个你已经完成过、但优化难度比较高的漏波天线作为基准测试。保留原有设计目标，然后分别测试人工优化、纯遗传算法、代理辅助多目标优化，以及增加结构操作库后的方法。
比较时使用相同的 HFSS 仿真预算，观察达标率、Pareto 前沿、计算时间和制造鲁棒性。这样才能证明系统是否真的更智能，而不只是调用了更多计算资源。
八、这个方向有没有研究价值？
有，而且我认为它可以进一步发展成一个研究课题。
不过，HFSS + MCP + LLM + 遗传算法 本身更像是软件系统集成。如果希望形成比较扎实的研究成果，关键创新应该是：
面向复杂电磁结构的物理知识引导、可行域保持和自适应结构搜索方法。
目前已经有针对天线优化的代理模型、多目标进化算法和贝叶斯优化研究，说明单纯把这些算法组合起来并不算特别新。
