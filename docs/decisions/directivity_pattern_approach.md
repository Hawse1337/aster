# 甜甜圈方向图结构路线决策（2026-11-18）

## 背景

用户要求把 AstraBB 的方向图做成 θ=90° 扁平甜甜圈（参考 Final 工程 7.78 dBi）。当前实心波纹盘只有 40°/125–140° 锥面。

## 决策

1. 先在授权的外圈周期参数内穷举方向图杠杆：环高径向渐变、馈源轴向偏移、盘厚、实心边缘环、径向平行板；全部真实 AEDT 实测，结果见 `docs/evidence/directivity_optimization.json`；
2. 这些杠杆都未形成 90° 甜甜圈，因此**暂停在“外圈周期参数”内继续试参**，不再消耗大算力；
3. 下一步建议（需用户确认）：把盘改成明确的双平板径向口径——盘面作为上板、下方加平行下板，边缘留径向开口缝隙/喇叭，中心由现有阶梯馈源激励；这是结构级改动，超出“外圈环参数”授权范围；
4. 若用户只接受外圈参数，则把现有最好结果作为折中：带宽版（基线/馈源偏移 −1.0 mm，7.0 GHz、峰值 4.5 dBi）或增益版（环高渐变 0.8，峰值 6.48 dBi、带宽 2.0 GHz）。

## 证据

- `docs/evidence/directivity_final_verdict.json`（验收对比与判定）
