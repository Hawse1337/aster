# 已知问题清单

本文件回答一个具体问题：**到目前为止发现的问题，哪些真的解决了、哪些还开着。**
每条都带修复版本与证据；测试（`tests/test_known_issues.py`）会检查这里引用的版本标签、
证据文件是否真实存在，以及"仍开放"的项是否也出现在 `docs/final_report.md` 的受限项里。

写法约定：

- **已解决** 必须有：修复版本（真实存在的 tag）+ 证据（文件或测试）；
- **仍开放** 必须写：为什么没解决、什么条件下能重开；
- 不写"应该解决了"这类没有证据的话。

## AstraBB 全带缺口（2026-11-18）

1. **24–32 GHz 全 8 GHz 连续带宽未达成**：最好 7.0 GHz（24–31，盘环距 1.0）。32 GHz 单独达标需要环距 ≈1.15，但 30 GHz 会掉出 −10 dB；均匀环距下缺口在带内移动，强径向渐变会分裂缺口。下一步建议：局部渐变（只改外圈 3–5 圈）、或盘外圈加微波吸收/阻抗渐变环。
2. **主瓣不在 θ=90°**：峰值在 θ≈42°/138°，θ=90° 面只是较弱的环；轴向偏移（feed_z_offset_mm）尚未实测。
3. **增益 4.18–5.09 dBi**：仍在参考 5–8 dBi 下沿；口径效率受盘面积/馈源遮挡限制。
4. **测量自动化不稳**：AEDT gRPC 启动竞态、campaign 工程名冲突（已用每变体独立 AEDT 规避）；单点求解 21–25 分钟，24–32 全套约 30 分钟。

## θ=90° 甜甜圈未达成（2026-11-18）

1. 允许改动范围内的 5 类结构试验（环高径向渐变、馈源轴向偏移、加厚盘体、实心边缘环、径向平行板）均未把主瓣放到 θ=90°，实测锥面只有 ~34–40° 与 ~124–142° 两组；
2. 最好 horizon 增益 = 基线 1.95 dBi，离 7 dBi 目标差距大；功率占比最高约 0.31（目标 0.85）；
3. 需要真正的赤道面口径：盘边缘径向开口/双平板缝隙/径向喇叭，属于结构级改动，需用户确认；
4. 实验纪律：每变体独立 AEDT、全带 24–32 GHz 六步自适应；失败与中途快照均在证据文件中标记，不当作验收数据。

## A 路线（波纹深度/边缘 taper）已否定（2026-11-19）

深波纹（峰值 4.5 mm / 外缘 3.0 mm）把主瓣从 40° 移到 32°，边缘 taper 归零（0.1 mm）把主瓣留在 38°；θ=90° 最大增益仅从 1.95 提到 2.54 dBi，功率占比仍约 0.29。结论：仅靠波纹深度/tpaer 改变 n_eff 无法让锥面经过 90°，慢波漏波路线在该参数范围被否定；下一步转 B（盘缘环缝口径）。证据：docs/evidence/directivity_optimization.json 的 route_A_leaky_wave。
