# 文献建议在设计台的应用

本轮把 T05、M02、E04、S09 和 M04 的建议接入已有结果数据。设计台在已完成的真实运行下自动补充 S11 检查。远场页在切换已保存的求解频点时同步更新环形波束指标。两个区块分别对应阻抗匹配和方向图，优化器仍按所选案例的既有约束运行。

| 入口 | 看到什么 |
| --- | --- |
| 设计台 S11 曲线 | 按运行案例的频带检查默认 −10 dB 匹配，标出最坏点、名义门限裕量和补扫区间。页面还要求 1 dB 保护裕量，最大采样间隙为 1 GHz。 |
| 设计台远场结果 | 按当前求解频点显示峰值 θ、赤道增益和方位波纹、近轴峰值、赤道到轴向峰值差及 θ=60°–120° 功率占比。完整球面和不超过 10° 的角度间隔是计算前提。 |
| 结果回放 CLI | 允许指定频带、门限、最大间隙及待验收的远场频点。`--astrabb-target` 对 Global 坐标的数据应用研究目标。 |
| 口径诊断 CLI | 用同一相位参考的圆柱面复电场计算 Ez 在切向电场中的份额、方位相干和扇区差异。 |
| 多保真验证 CLI | 在同几何、同观测域的低高保真配对上回测误差、排序、误筛和端到端耗时。 |

有限 S11 点可以证伪全带达标。点集通过时仍需密扫证实连续频带。只有 S11 扫频数据时，方向图覆盖仍以各频率实际保存的远场为准。口径场相干及场平方积分用于诊断，单位和物理含义与辐射功率不同。

环带功率比例按线性 `GainTotal` 除以同频全球积分计算，极角权重使用 `d(cos θ)`，φ 周期接缝只计算一次。这是归一化角分布，不是绝对效率。近轴区域为两极 30° 球冠，赤道到轴向峰差使用两极 45° 球冠。旧回放脚本直接对网格样本作不加权求和，因此旧功率比例与新立体角比例不可直接比较。研究预设 `astrabb_equatorial_v2` 包含赤道 7 dBi、纹波 2 dB、赤道到轴向差 15 dB、近轴 −5 dBi 及环带比例 0.85 五个方向图门限，在单个求解频点判定。它不替代 `lens28_var` 的优化目标。

## 用法

在 `<repo>` 中启动源码版设计台。页内选中相应结果即可看到新指标。离线回放使用 `runs` 目录中的守护运行 ID：

```powershell
$python = '<guard-repo>\.venv\Scripts\python.exe'
& $python -B -m antopt.acceptance --campaign '<workspace>\verify_20261118\campaign_lens2' --run-id 20261118T041651340500 --band 24 32 --pattern-frequencies 24 28 32 --astrabb-target
& $python -B -m antopt.aperture --example
& $python -B -m antopt.aperture '.\rim_complex_e.csv' --sectors 3 --output '.\rim_diagnostic.json'
& $python -B -m antopt.surrogate.coarse_validation --help
```

口径输入需要真实复数 Ex/Ey/Ez、完整 φ×z 网格和共同相位参考。当前保存的 AstraBB 远场为幅值，合成用例验证了算法和文件入口。实用时需补导出环缝复近场。

低保真门默认至少需要 24 个独立配对，并按几何做训练、校准和盲测。配对要求真实频轴、参考面、指标定义和测量契约相容。对现有 6 个已完成运行的只读审计显示证据不足，设计台没有启用自动粗筛。生成或压缩响应、训练网络及增加结构自由度须在有效数据上单独做总预算对照。
